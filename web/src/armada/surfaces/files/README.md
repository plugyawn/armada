# surfaces/files

The Files view: the tree and the source across the whole composition.

Not here: another surface's internals, a raw `<button>`, `<input>`, `<select>` or `<dialog>` (use `kit/`), a network call (use `state/` and `api/`).

To add one: keep the four seams: `index.tsx`, `files.css`, `commands.ts`, `showroom.tsx`; a part is a file beside them.
