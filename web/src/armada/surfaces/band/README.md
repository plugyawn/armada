# surfaces/band

The one line above the field: a run's state word, clock and Stop, a question, a queue notice, a typing person, and the model and effort at its far end.

Not here: another surface's internals, a raw `<button>`, `<input>`, `<select>` or `<dialog>` (use `kit/`), a network call (use `state/` and `api/`).

To add one: keep the four seams: `index.tsx`, `band.css`, `commands.ts`, `showroom.tsx`; a part is a file beside them.
