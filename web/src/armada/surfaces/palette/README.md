# surfaces/palette

The command palette (Cmd-K) and message search results.

Not here: another surface's internals, a raw `<button>`, `<input>`, `<select>` or `<dialog>` (use `kit/`), a network call (use `state/` and `api/`).

To add one: keep the four seams: `index.tsx`, `palette.css`, `commands.ts`, `showroom.tsx`; a part is a file beside them.
