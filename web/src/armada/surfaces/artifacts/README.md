# surfaces/artifacts

Artifact blocks in the conversation and their renderers, loaded by kind when one is opened.

Not here: another surface's internals, a raw `<button>`, `<input>`, `<select>` or `<dialog>` (use `kit/`), a network call (use `state/` and `api/`).

To add one: keep the four seams: `index.tsx`, `artifacts.css`, `commands.ts`, `showroom.tsx`; a part is a file beside them.
