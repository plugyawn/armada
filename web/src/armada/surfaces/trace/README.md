# surfaces/trace

A step's trace, shown in the column when a step is pressed.

Not here: another surface's internals, a raw `<button>`, `<input>`, `<select>` or `<dialog>` (use `kit/`), a network call (use `state/` and `api/`).

To add one: keep the four seams: `index.tsx`, `trace.css`, `commands.ts`, `showroom.tsx`; a part is a file beside them.
