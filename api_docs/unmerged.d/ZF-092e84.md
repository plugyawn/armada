* [`GET /messages`](/api/get-messages), [`GET /messages/{message_id}`](/api/get-message),
  [`GET /events`](/api/get-events): The message object's boolean field
  saying whether the agent's bot sent the message is renamed to
  `is_agent_message`. Its earlier name, which carried the agent's old code
  name, is no longer sent.
* The agent's undocumented wire names lost the old code name in the same
  change: the events `agent_run` and `workspace_changed`, the
  `POST /register` keys `agent_user_ids` and `repository_stream_ids`, the
  `POST /messages` parameter `agent_followup`, the channel-creation
  parameter `repository_url`, the submessage type `artifact`, and the
  routes under `/json/armada/`. The earlier names are not accepted.
