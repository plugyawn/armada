# surfaces/composer

The field: one raised capsule with Plus, the words, the agent's toggle and the default button; the outbox behind it. `origin.ts` is the one file here that may measure.

Not here: another surface's internals, a raw `<button>`, `<input>`, `<select>` or `<dialog>` (use `kit/`), a network call (use `state/` and `api/`).

To add one: keep the four seams: `index.tsx`, `composer.css`, `commands.ts`, `showroom.tsx`; a part is a file beside them.
