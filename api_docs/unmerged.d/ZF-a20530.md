**Feature level ZF-a20530**

* [`POST /scheduled_messages`](/api/create-scheduled-message),
  [`POST /reminders`](/api/create-message-reminder): Added an
  `agent_run_id` parameter, given instead of
  `scheduled_delivery_timestamp`, to send the scheduled message or the
  reminder when that agent run first ends (done, failed or cancelled)
  instead of at a time. `scheduled_delivery_timestamp` is no longer
  required when `agent_run_id` is given.
* [`GET /scheduled_messages`](/api/get-scheduled-messages),
  [`GET /reminders`](/api/get-reminders), [`POST /register`](/api/register-queue),
  [`GET /events`](/api/get-events): Scheduled message and reminder
  objects have a new `agent_run_id` field, present only while they wait
  for an agent run; their `scheduled_delivery_timestamp` is then a
  placeholder far in the future.
* [`PATCH /scheduled_messages/{scheduled_message_id}`](/api/update-scheduled-message):
  A `scheduled_delivery_timestamp` given to a scheduled message that
  waits for an agent run replaces the wait.
