# surfaces/changes

The Changes view: the diff with review's tools (fold, Viewed, context on demand, lines sent to the agent).

Not here: another surface's internals, a raw `<button>`, `<input>`, `<select>` or `<dialog>` (use `kit/`), a network call (use `state/` and `api/`).

To add one: keep the four seams: `index.tsx`, `changes.css`, `commands.ts`, `showroom.tsx`; a part is a file beside them.
