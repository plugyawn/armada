# surfaces/lists

The column's plain lists: Changes, Runs and People on a worktree; Threads, Shared and Together elsewhere. Every row is something one opens, in one row grammar.

Not here: another surface's internals, a raw `<button>`, `<input>`, `<select>` or `<dialog>` (use `kit/`), a network call (use `state/` and `api/`).

To add one: keep the four seams: `index.tsx`, `lists.css`, `commands.ts`, `showroom.tsx`; a part is a file beside them.
