# surfaces/checklist

A run's plan as the working checklist: steps with their marks and durations, what the step in hand is doing, and the record of a finished run.

Not here: another surface's internals, a raw `<button>`, `<input>`, `<select>` or `<dialog>` (use `kit/`), a network call (use `state/` and `api/`).

To add one: keep the four seams: `index.tsx`, `checklist.css`, `commands.ts`, `showroom.tsx`; a part is a file beside them.
