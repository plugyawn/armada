# surfaces/dialogs

The dialog for what cannot be undone, menus and context menus.

Not here: another surface's internals, a raw `<button>`, `<input>`, `<select>` or `<dialog>` (use `kit/`), a network call (use `state/` and `api/`).

To add one: keep the four seams: `index.tsx`, `dialogs.css`, `commands.ts`, `showroom.tsx`; a part is a file beside them.
