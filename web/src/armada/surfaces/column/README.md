# surfaces/column

The host beside the conversation and its registry of contents; below the threshold the same contents open as a sheet.

Not here: another surface's internals, a raw `<button>`, `<input>`, `<select>` or `<dialog>` (use `kit/`), a network call (use `state/` and `api/`).

To add one: keep the four seams: `index.tsx`, `column.css`, `commands.ts`, `showroom.tsx`; a part is a file beside them.
